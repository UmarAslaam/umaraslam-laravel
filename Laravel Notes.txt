(1) Fisrt Project Settup command

(a) You make folder and in folder you open cmd and these command written:

(b) composer create-project "laravel/laravel:^10.0" first app --no-security-blocking
(c) cd first app 
(d) php artisan serve

(2) How to make controller :
php artisan make:controller ProductController

(3) How to make router 2 step follow :

(a) Route::get('/', [ProductController::class,"index"]);

(b) controller import on top in web.php file :
use App\Http\Controllers\ProductController;
